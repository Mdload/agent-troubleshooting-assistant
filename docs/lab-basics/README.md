# 实验室工作入门知识库

2026-10-12基础版：7类、28个小主题。每篇按用途→基础概念→少量常用命令→常见问题组织，供入门与查用，后续按真实反馈迭代。

| 类别 | 主题 |
|---|---|
| [Linux日常操作](linux.md) | 文件与路径；用户与权限；进程与资源；磁盘与文件大小 |
| [网络基础](network.md) | IP与路由；DNS与域名；TCP/UDP及端口；NAT与回程 |
| [远程访问与传输](remote.md) | SSH；SCP/SFTP；SSH端口转发；代理与HTTPS |
| [程序与服务](services.md) | systemd状态；启动与自启；日志与时间；HTTP/nginx/Node |
| [数据库基础](database.md) | 数据库与表；SELECT；连接问题；备份与导出 |
| [测试与实验数据](testing.md) | ping；iperf；抓包；实验记录与数据整理 |
| [脚本与开发环境](development.md) | Python脚本；虚拟环境；JSON接口；Git |

正文为独立整理的浅层说明，各小主题保留官方手册或官方发行版提供的项目手册入口；核对范围为所用基础概念与示例，资料日期不是设备采集日期。不同软件版本、平台和权限会影响具体选项，应结合实际手册。

加载入口是[lab_basics.py](../../lab_basics.py)与[knowledge.py](../../knowledge.py)，KB-101～KB-128是固定引用编号；通过现有BM25检索及正式/api/chat接入。没有新增模型、数据库连接或任意shell工具。

通用资料只支持概念和示例，不确认实验室实际端口、地址、账号、安装路径、业务关系或当前运行状态。原[拓扑知识](../topology/README.md)保留其历史日期与模式边界；Croc继续以基本原理为主，没有加入算法91或版本操作手册。

示例命令不是已执行动作；文件写入、服务控制、安装、Git提交、主动流量与抓包均在操作者获准的范围执行。数据库章节不代表已获准登录或查询真实数据。
